# 15-Week Agile Plan

| Week | Goal | Major Tasks | Expected Deliverable | Dependencies | Completion Condition |
|---|---|---|---|---|---|
| **1** | Define Scope | Problem definition, Scope boundaries | Week 1 Docs | None | Scope approved & frozen |
| **2** | Agile Planning | Backlog, stories, workflows | Week 2 Docs | Week 1 Scope | Planning artifacts approved |
| **3** | Setup | Pick language, DB, architecture | Tech Stack Doc | Week 2 Plan | Tools installed locally |
| **4** | Version Control | Init Git repo, branch strategy | GitHub Repo | Week 3 Setup | Repo accessible & documented |
| **5** | Feature Dev | Build submission/validation | Feature Branch Code | Week 4 Repo | App compiles locally |
| **6** | MVP Complete | Build review dashboard | Merged Main Branch | Week 5 Code | MVP runs locally bug-free |
| **7** | CI Intro | Install Jenkins, basic trigger | Jenkins Server/Job | Week 6 MVP | Commit triggers a build |
| **8** | Pipeline Code | Write Jenkinsfile | Pipeline Job | Week 7 CI | Jenkinsfile drives build |
| **9** | Automation | Write Selenium UI tests | Test Scripts | Week 6 MVP | Tests pass locally |
| **10** | CI Testing | Add tests to Jenkins | Jenkins Pipeline | Week 8 & 9 | Build fails if test fails |
| **11** | Containers | Write Dockerfile | Docker Image | Week 6 MVP | App runs in local container |
| **12** | CD Intro | Jenkins runs container | CD Pipeline | Week 10 & 11 | Jenkins deploys container |
| **13** | Config Mgmt | Write Ansible/Puppet scripts | Config Scripts | Week 12 CD | Scripts execute locally |
| **14** | Auto Provision| Jenkins uses config mgmt | End-to-End Pipeline | Week 13 Scripts| Full pipeline success |
| **15** | Final Viva | Polish, document | Final Project Release| Week 14 | Viva completed |
