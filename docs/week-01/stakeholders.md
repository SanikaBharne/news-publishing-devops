# Stakeholders

## Target Users

| User Type | Description |
|---|---|
| News Writers / Journalists | Users who submit news articles/requests for review. |
| Reviewers / Editors | Users who review submissions, request changes (reject with mandatory comments), or approve articles. |

## Stakeholders

| Stakeholder | Description |
|---|---|
| Development & Operations Team (You) | Responsible for building the application and implementing the DevOps pipeline. |
| Academic Evaluators / Instructors | Assessing the implementation of DevOps principles, practices, and final project documentation. |

## Roles and Responsibilities

| Role | Responsibilities |
|---|---|
| DevOps Engineer (Student) | Develop the monolithic application MVP, configure Git/GitHub, build Jenkins pipelines, write Selenium tests, containerize with Docker, and manage infrastructure with Ansible/Puppet. |
| Evaluator (Instructor) | Provide feedback, evaluate the pipeline's reliability, verify success criteria, and grade the final presentation/viva. |

## Expectations

- **Development & Operations Team:** Expects to gain hands-on experience in building a complete CI/CD pipeline and configuration management system from scratch.
- **Evaluators:** Expect a demonstrable, automated pipeline where a code commit securely and reliably traverses through build, test, and deployment stages without manual intervention, accompanied by proper documentation.
