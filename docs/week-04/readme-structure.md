# README Structure

The `README.md` was rewritten in Week 4 to serve as a professional landing page for the repository. It includes the following sections:

1.  **Project Description:** High-level overview of the 15-week DevOps academic project.
2.  **Problem Statement:** The need for automated CI/CD workflows.
3.  **MVP Scope:** The strict boundaries of the application (submission, review, dashboard, status tracking).
4.  **Key Features:** Split into "Currently Implemented" and "Planned for Future Weeks".
5.  **Technology Stack:** Table of tools (Python, Flask, SQLite, Jenkins, Docker, etc.) with current installation status.
6.  **Project Structure:** A tree representation of the repository.
7.  **Current Project Status:** Explicitly states that Week 4 is completed and feature development hasn't started.
8.  **How to Run Locally:** Clear commands to install dependencies and run the Flask skeleton.
9.  **How to Run Tests:** Placeholder for Week 5-6 test commands.
10. **Git Branching Strategy:** Defines `main`, `development`, and `feature/*` branches.
11. **15-Week Roadmap:** Tracks progress across the entire semester.
12. **Documentation Links:** Direct links to weekly summaries.
13. **Future DevOps Components:** A disclaimer section ensuring that future tools (Jenkins, Docker) are not falsely claimed as implemented yet.
